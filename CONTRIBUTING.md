# Contributing

Corrections and beginner-friendly improvements are welcome.

1. Fork this repository and create a focused branch.
2. Make the smallest change that solves the problem.
3. Run `npm ci` and `npm run check`.
4. Open a pull request using the provided checklist.

Do not include credentials, personal learner data, or screenshots containing private information. By participating, you agree to follow the [MMAUG Code of Conduct](https://mmaug.com/code-of-conduct).
